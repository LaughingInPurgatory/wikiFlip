# Welcome to WikiFlip

## What is WikiFlip?

WikiFlip is a lightweight, flat-file knowledge base. Pages are stored as **Markdown** under `pages/` — no database server required.

## Features

- WYSIWYG + Markdown editing (Toast UI)
- Categories with nested sub-pages
- Images and PDFs stored next to `content.md` as relative paths
- deep-indigo glass theme

## Getting started

Open **Admin** to create a top-level page or nest a sub-page under one. Public pages use `?slug=your-page-slug`.
